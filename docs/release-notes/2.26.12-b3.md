# BD-SpineX 2.26.12-b3

Hotfix for **PlayCover BrownDust II 2.26.12**.

## What's Fixed

- 🧩 Fixes multi-`__data` patch planning when one bundle already contains inserted atlas pages.
- 🖼️ Improves mods that add extra PNG pages, including `Wilhelmina Date illust_dating6LC`.
- 🧹 Restoring a mod now removes extra inserted Texture2D, Material, Atlas references, and bundle entries.
- 🔁 Prevents old same-asset mods from leaving mixed `__data` states after replacement.

## Notes

- ✅ Use this release with BrownDust II **2.26.12**.
- 🔁 Existing BD-SpineX data for `2.26.12` is reused by this hotfix build.
- 📦 The DMG includes the required `2.26.12` index files.
- 🍎 macOS Apple Silicon build only.
- ⚠️ This app is unsigned. macOS may ask you to approve it manually the first time.
