# BD-SpineX 2.26.12-b4

Hotfix for **PlayCover BrownDust II 2.26.12**.

## What's Fixed

- 🧩 Fixes multi-page PNG planning when local index data says extra atlas pages already exist but the live `__data` does not.
- 🖼️ Extra atlas pages now use the safer UABEA insert/reuse path across every matching `__data`.
- 🛠️ Failed mods can now enter **Fix** mode, making it easier to recover from older failed patch history.
- 🔁 Helps mods such as `Eclipse Date illust_dating11black` recover without manually clearing history.

## Notes

- ✅ Use this release with BrownDust II **2.26.12**.
- 🔁 Existing BD-SpineX data for `2.26.12` is reused by this hotfix build.
- 📦 The DMG includes the required `2.26.12` index files.
- 🍎 macOS Apple Silicon build only.
- ⚠️ This app is unsigned. macOS may ask you to approve it manually the first time.
