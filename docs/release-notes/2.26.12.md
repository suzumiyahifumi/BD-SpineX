# BD-SpineX 2.26.12

Release for **PlayCover BrownDust II 2.26.12**.

## What's New

- 🎯 Adds bundled index data for BrownDust II **2.26.12**.
- 🔁 Improves version update handling for users coming from older patched installs.
- 🧭 Uses the bundled game index first during update checks, reducing unnecessary Shared rescans.
- 🌳 Refines **Patch Status** into a clearer `__data`-based view with collapsible rows.
- 🛠️ Allows repair mode for `changed` entries, making recovery easier when old backup state no longer matches the current game file.
- 💿 macOS release packaging now focuses on the DMG installer.

## Notes

- ✅ Use this release with BrownDust II **2.26.12**.
- 📦 The DMG includes the required `2.26.12` index files.
- 🍎 macOS Apple Silicon build only.
- ⚠️ This app is unsigned. macOS may ask you to approve it manually the first time.
