01 — Design Philosophy

克制、深邃、流動。

三條原則貫穿整個重建：以 Apple Human Interface Guidelines 的「內容優先」收斂視覺噪音；以暗色玻璃讓 BrownDust II 的角色色彩成為光源；以實體卡匣的觸感把抽象的「掛載/卸載」變成可以拿在手上的東西。

🍎 內容優先

去除邊框、分隔線與裝飾色塊。資訊以層級（typography + 空間）區分，而非框線。每個畫面只保留一個主要動作。

🌑 深邃暗色

以 #06070d 為畫布，背後流動的極光（aurora）提供玻璃折射所需的光。介面不發光，而是讓內容發光。

💎 真實質感

玻璃會折射、會反光、會隨內容滾動而扭曲背景。卡匣有重量、有插槽、有觸點。互動有物理回饋。

02 — The Core Metaphor

從唱片夾，到卡匣收藏。

音樂播放器把歌曲收進唱片夾；我們把模組收進卡匣盒。每個模組是一張 SNES／Game Boy 風格的遊戲卡帶——有印刷標籤、有作者、有分類色、底部有金色接觸點。掛載一個模組，就是把卡匣「插進」遊戲。

03 — The Liquid Glass System

真正會折射的玻璃。

參考 kube.io 的作法：用 SVG feTurbulence 產生雜訊、feGaussianBlur 柔化，再用 feDisplacementMap 依雜訊位移背景像素，最後把整個 filter 掛進 CSS 的 backdrop-filter。本頁所有玻璃面板都是即時運算的——滑動頁面，看背後極光被玻璃彎折。

styles · liquid-glass.css
/* 1) 折射鏡片：雜訊 → 位移背景 */
<filter id="liquid-lens">
  <feTurbulence type="fractalNoise"
     baseFrequency="0.008 0.012"
     numOctaves="2" seed="42" result="noise"/>
  <feGaussianBlur in="noise"
     stdDeviation="2.2" result="soft"/>
  <feDisplacementMap in="SourceGraphic"
     in2="soft" scale="56"
     xChannelSelector="R" yChannelSelector="G"/>
</filter>

/* 2) 掛進 backdrop-filter（Chromium / Electron）*/
.glass__filter {
  backdrop-filter: blur(2px)
     url(#liquid-lens) saturate(1.7);
}
/* 3) 三層疊加：tint 著色 + shine 高光環 */
即時範例
這塊玻璃是活的。
捲動頁面，背後的極光會被它折射、放大、扭曲。
ℹ️
相容性：SVG-backed backdrop-filter 目前僅 Chromium／Electron 完整支援——對本 app（Electron）正好完美。其他環境自動降級為多層 blur() 玻璃，質感仍在。建議封裝為 <LiquidGlass> React 元件，並支援 prefers-reduced-transparency。

參數對照

baseFrequency

0.008–0.012
越低 → 波紋越大、越像厚玻璃。

scale

40–70
位移強度。卡匣 hover 時可拉高製造「液化」感。

blur

2–14px
霧化程度。前景面板低、背景遮罩高。

saturate

1.6–1.8
讓被折射的角色色彩更鮮活。

📦
可選套件：liquid-glass-react / @specy/liquid-glass 等社群元件，或直接採用本頁的原生三層實作（零相依、最可控）。建議自建，因為要綁定卡匣與面板的圓角與互動。

05 — Information Architecture

資訊架構。

09 — Implementation Plan

怎麼把它蓋出來。

不動 Electron 主程序與 IPC（window.bd2.* 全部沿用），重建只發生在 renderer。分階段落地，每階段都可獨立運行。

1

導入暗色玻璃主題層

新增 tokens.css + liquid-glass.css，把既有 styles.css 改寫為暗色玻璃版本（沿用所有 class 名，零邏輯變更）。本次已先落地這一步。

2

抽出 <LiquidGlass> 元件

封裝三層結構與 SVG lens，提供 tint / radius / intensity props 與 reduced-transparency 降級。

3

側欄 + 分頁路由

頂部工具列改為左側玻璃 rail：Library / Roster / Profiles / Preview / Stats / Settings。

4

卡匣化模組列表

把現有表格換成 <Cartridge> grid，狀態（available/mounted/conflict）對應現有 desired/mounted/tones 邏輯。

5

卡匣播放器 dock

底部常駐，綁定 pendingChanges 與 applyChanges()／launchGame()。

6

新功能：Profiles / Roster / Preview / Stats

新增 IPC 與資料模型（作者、角色 ID 對照、Spine viewer）。可漸進交付。

🧩
技術棧：維持 React 19 + Vite + Electron 37。液態玻璃用原生 SVG filter（已驗證於 Chromium backdrop-filter），動畫用 CSS + framer-motion（選用）。Spine 預覽可接 @esotericsoftware/spine-player / pixi-spine。
