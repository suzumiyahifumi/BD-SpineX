# BD-SpineX 2.25.19-b3

Emergency hotfix for **PlayCover BrownDust II 2.25.19**.

## What's Fixed

- 🚀 Adds **Force ASTC Mode** for faster UABEA-based Texture2D patching.
- 🧩 Keeps **Original UABEA** and **UnityPy** selectable for troubleshooting.
- 🖼️ Improves ASTC/iOS texture patch compatibility without falling back to RGBA32.
- 🔒 Fixes a Mod Power lock edge case where saved state could not be restored when no patch plan was loaded.
- 🧪 Keeps hotfix data under the same BrownDust II `2.25.19` history folder.

## Notes

- ✅ Use this release with BrownDust II **2.25.19**.
- 🔁 Existing BD-SpineX data for `2.25.19` is reused by this hotfix build.
- 🍎 macOS Apple Silicon build only.
- ⚠️ This app is unsigned. macOS may ask you to approve it manually the first time.
