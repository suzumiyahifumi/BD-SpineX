# BD-SpineX 2.25.19

macOS mod manager for the PlayCover version of **BrownDust II 2.25.19**.

## Highlights

- ✨ New guided help popups beside key controls
- 🧭 Shared Folder guide with one-click Finder opening for the detected PlayCover Shared folder
- 📁 Recursive Mods scan for nested source/author/category folders
- 🔒 Safer lock states during patch actions, Mod Power, missing settings, and version mismatch
- 🧩 Versioned history/backups to avoid reusing stale game `__data` hashes after updates
- 🚀 Includes required backend tools; no backend build step needed after install

## Recommended First Steps

1. Open BD-SpineX.
2. Set **Shared Folder** and **Mods Folder**.
3. Use **Scan Mods**.
4. Use **Scan Shared for Mods** if you need to refresh matching assets.
5. Select mods and press **Apply Changes**.
