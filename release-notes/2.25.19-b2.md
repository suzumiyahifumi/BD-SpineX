# BD-SpineX 2.25.19-b2

Emergency hotfix for **PlayCover BrownDust II 2.25.19**.

## What's Fixed

- 🚑 Bundles the UnityPy patch backend into the macOS app.
- 🧩 Auto/UABEA/UnityPy backend selection no longer requires users to install Python packages.
- 🖼️ Fixes Texture2D patch flows that need UnityPy's native texture dependencies.
- 🔖 Adds hotfix-style versioning such as `2.25.19-b2` while still matching BrownDust II `2.25.19`.

## Notes

- ✅ Use this release with BrownDust II **2.25.19**.
- 🔁 Existing BD-SpineX data for `2.25.19` is reused by this hotfix build.
- 🍎 macOS Apple Silicon build only.
- ⚠️ This app is unsigned. macOS may ask you to approve it manually the first time.
