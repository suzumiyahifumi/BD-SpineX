# BD-SpineX 2.27.19

Release for **PlayCover BrownDust II 2.27.19**.

## What's New

- 🎯 Adds bundled index data for BrownDust II **2.27.19**.
- 🧼 Rebuilt the bundled `2.27.19` index from a clean reinstall of BrownDust II.
- 🧾 Includes SHA-256 indexed `__data` records for safer update checks.
- 🔁 Keeps older versioned indexes so BD-SpineX can reason about previous patched installs.
- 🧹 Cleans old version patch history and backup data after a successful version migration to reduce storage usage.
- 📂 Adds an **Open Records Folder** button so users can quickly find patch history, backups, and migration reports.
- 🧱 Fixes patch checks for large `__data` / backup files over 2 GiB by using streaming SHA-256 reads.
- 🧩 Carries forward multi-page PNG patch and restore improvements from recent hotfixes.
- 🛠️ Keeps Fix mode available for patched, changed, or failed mod entries.
- 💿 macOS release packaging focuses on the DMG installer.

## Notes

- ✅ Use this release with BrownDust II **2.27.19**.
- 📦 The DMG includes the required `2.27.19` index files.
- 🛟 Old backups are kept if migration is partial or failed, so recovery data is not removed too early.
- 🍎 macOS Apple Silicon build only.
- ⚠️ This app is unsigned. macOS may ask you to approve it manually the first time.
