# BD-SpineX 2.26.12-b2

Hotfix for **PlayCover BrownDust II 2.26.12**.

## What's Fixed

- 🖼️ Restores UABEA support for mods that add extra atlas PNG pages.
- 🔎 Extra PNG pages are inserted only when the mod's `.atlas` actually references them.
- 🧩 Mods with additional Texture2D pages now use the UABEA ASTC insert path automatically.
- ✅ Fixes patch planning for mods such as `Wilhelmina Date illust_dating6LC`.

## Notes

- ✅ Use this release with BrownDust II **2.26.12**.
- 🔁 Existing BD-SpineX data for `2.26.12` is reused by this hotfix build.
- 📦 The DMG includes the required `2.26.12` index files.
- 🍎 macOS Apple Silicon build only.
- ⚠️ This app is unsigned. macOS may ask you to approve it manually the first time.
