# BD-SpineX 2.27.19-ex1

Experimental runtime release for **PlayCover BrownDust II 2.27.19**.

## ✨ What's New

- 🧩 Adds Runtime Injection support using the bundled `libbd2loader.dylib`.
- 📦 Mounts mods into the PlayCover game container instead of patching `__data` directly.
- 📁 Adds recursive Mods Folder scanning, including nested folders.
- 🔄 Adds `Refresh Mods` so users can manually rescan the Mods Folder.
- Adds locked mod actions with clearer guidance when injection, game app, version, or Mods Folder setup is missing.
- Adds red/green injection status so `Not injected` and `Injected` are easier to read.
- Adds `Mod Power` to turn mounted runtime mods off or back on without moving mod folders.
- Changes `Restore All` to unmount all runtime mods while keeping Runtime Injection installed.
- Adds confirmation dialogs for destructive or high-impact actions.
- Adds old Patch upgrade handling with three choices: `Do Nothing`, `Unpatch Only`, or `Migrate`.
- Removes private hardcoded paths from the native loader and release build checks.
- Fixes the native loader path detection inside PlayCover so it uses the correct game container `Data/bd2mods` folder.
- Updates the UI copy to English and refines spacing, hover states, badges, and help popovers.

## ⚠️ Upgrade Notes

- Use this release with BrownDust II **2.27.19**.
- If you used an older `__data` Patch build, BD-SpineX will offer migration choices when old patch records are detected.
- If you choose `Migrate`, close the game first and set your Mods Folder before continuing.
- After updating BrownDust II, run `Install Runtime Injection` again.
- Runtime mods may briefly stutter the first time a matching asset appears in-game because files are loaded and built at runtime.

## 📝 Known Notes

- macOS Apple Silicon build only.
- The app is unsigned, so macOS may ask you to approve it manually the first time.
- Runtime Injection does not manage PlayCover login, Keychain, or PlayChain state.
- `Launch Game` opens the PlayCover app bundle through macOS; it does not modify login data.
