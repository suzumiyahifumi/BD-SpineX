# BD-SpineX 2.28.10

Runtime update release for **PlayCover BrownDust II 2.28.10**.

## What's New

- Adds bundled index data for BrownDust II **2.28.10**.
- Updates Runtime Injection IL2CPP RVA targets for BrownDust II **2.28.10**.
- Rebuilds the bundled `libbd2loader.dylib` with the new runtime targets.
- Includes SHA-256 indexed `__data` records for safer update checks.
- Keeps older versioned indexes so BD-SpineX can reason about previous patched installs.

## Upgrade Notes

- Use this release with BrownDust II **2.28.10**.
- After updating BrownDust II, run `Install Runtime Injection` again.
- Runtime mods may briefly stutter the first time a matching asset appears in-game because files are loaded and built at runtime.

## Known Notes

- macOS Apple Silicon build only.
- The app is unsigned, so macOS may ask you to approve it manually the first time.
- Runtime Injection does not manage PlayCover login, Keychain, or PlayChain state.
