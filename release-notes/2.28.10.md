# BD-SpineX 2.28.10

Release for **PlayCover BrownDust II 2.28.10**.

## Highlights

- ✅ Supports BrownDust II **2.28.10**.
- 🖼️ Adds the new poster-style **Library** experience with cartridge cards, clearer mounted/staged states, and easier pending-change review.
- 🎭 Adds a stronger **Roster** workflow so you can browse mods by character instead of searching through folders.
- 👁️ Adds the new **Preview** page for checking supported Spine mods before installing.
- 🔀 Preview can compare up to two mods, switch animations, stack animation tracks, and adjust visible parts.
- 🧭 Pending Changes can now guide you back to the matching cartridge more easily.
- 🛡️ Adds clearer confirmation prompts for risky actions such as **Apply Changes**, **Restore All**, **Mod Power**, and author label resets.
- 🚫 BD-SpineX now does a better job stopping mod changes while BrownDust II is running, helping avoid broken or half-applied changes.
- 🔗 If your game version does not match, **Settings → About** now points you to the GitHub releases page.
- 📦 Release packaging has been cleaned up so the Tauri app only carries the resources it needs.

## Upgrade Notes

- Use this release with BrownDust II **2.28.10**.
- After updating BrownDust II, open BD-SpineX and run **Install Runtime Injection** again.
- Close BrownDust II before installing or removing Runtime Injection, applying changes, using Mod Power, or restoring all mods.
- Runtime mods may briefly stutter the first time a matching asset appears in-game.

## Known Notes

- macOS Apple Silicon build only.
- The app is unsigned, so macOS may ask you to approve it manually the first time.
- Runtime Injection does not manage PlayCover login, Keychain, or PlayChain state.
