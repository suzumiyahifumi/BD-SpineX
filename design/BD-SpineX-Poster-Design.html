01 — 設計主張

四個判斷

在動手配色前，先講清楚「印刷感」和你現有資產（玻璃、卡帶）的真實取捨。

1

印刷感 ≠ 背景變米黃

真正的海報感來自油墨、粗壓縮字體、全大寫字距、斜切紅帶、巨大數字、厚規線與半色調網點。顏色只是其一。

2

玻璃需要深色

液態玻璃靠深色高對比背景才折射出立體；疊在米黃紙上會變平變髒。你的灰塑膠卡帶在大片米黃上對比也會散掉。

3

深色印刷台 + 紙張外框

工作區（卡帶牆、dock）維持深色讓玻璃發揮；印刷感集中在側欄、標題、按鈕、空狀態、徽章等 chrome。

4

暖色位移：CP 值最高

把冷藍黑 #06070d 換成暖近黑、白字換奶油色、藍灰玻璃換暖調。幾乎不動結構，識別度立刻跳一階。

03 — 按鈕

平面印刷 × 液態玻璃

靜止＝印刷（實色填充、1.5px 硬油墨描邊、方角、套色偏移陰影）；hover／active＝玻璃（backdrop 模糊＋透鏡）。把滑鼠移上去看它從印刷「翻成」玻璃。

← 靜止是印刷；hover 變玻璃＋下沉 1px（像被按進紙裡）

box-shadow:3px 3px 0 var(--red-deep) 是模仿印刷「套色沒對準」的硬偏移，取代柔光暈；hover 時加上 backdrop-filter: blur() url(#lens) 才出現玻璃。

06 — 落地

怎麼蓋

三套配色全用 CSS 變數，掛在 :root[data-theme]，加一個切換就能即時換。卡帶／dock 的深色 tray 用獨立變數，不被主題的亮底影響。

app/renderer/src/styles.css — theme tokens
:root[data-theme="night"] {
  --ink:#0E0D0C; --paper:#EDE0C4;
  --red:#E2402A; --red-deep:#9E2317; --amber:#E8A22C;
  --tray:#0a0907;  --glass:rgba(237,224,196,.08);
}
:root[data-theme="riso"] {  --ink:#1B1714; --paper:#F0E3C6;
  --red:#C8372A; --amber:#D9772A; --tray:#14120E; }

.btn { background:var(--red); border:1.5px solid var(--red-deep);
       border-radius:5px; box-shadow:3px 3px 0 var(--red-deep); }
.btn:hover { backdrop-filter:blur(6px) url(#liquid-lens) saturate(1.5); }

變動檔案：styles.css（token＋按鈕＋側欄／標題印刷化）、App.tsx（主題切換、巨數、把綠勾換成蓋章勾）。卡帶元件不動。

07 — 設計重點總結（已落地）

十條原則 · 已實作

A Night Press 已做成 app 可切換主題（Classic／Night Press／Risograph／Constructivist，設定頁切換、localStorage 記憶）。以下是貫穿這次落地的設計判斷，當作日後維護與擴充的準則。

1

深色印刷台優先

工作區（卡帶牆、dock）維持深色，玻璃與卡帶才有對比；亮色主題（Riso/Mono）則「紙張側欄 + 深色 tray 主畫面」分區，用 .appMain 局部變數翻成深色。

2

暖色位移

冷藍黑 → 暖近黑 #0E0D0C、白字 → 奶油 #EDE0C4、藍灰玻璃 → 暖調。識別度最大、結構不動。

3

單一主墨 + 一輔

紅為主墨（rail active／標題底線／stamp／Apply），琥珀為輔（巨數／徽章／左側 tab），黃極少量。紅橘黃不等重並陳。

4

壓縮字 + 全大寫

標題／側欄／按鈕／徽章用 BD Label Condensed 全大寫加字距；中文 BD Label TC；內文維持 SF。

5

巨數即海報

把掛載計數做成琥珀巨數＋紅色套色偏移陰影，當標題列的視覺主角（僅海報主題顯示）。

6

按鈕：印刷 ↔ 玻璃

靜止＝平面印刷（實色填充、1.5px 硬描邊、方角、3px 3px 0 套色偏移）；hover＝下沉 1px＋液態玻璃。dock 與工具鈕維持原玻璃。

7

斜切 / 紅帶 / 星

標題底厚紅線、rail logo 斜切、區段紅規線；幾何與斜切是印刷感的骨架。

8

綠勾 → 紅蓋章

選取記號從綠勾改成紅色「蓋章」勾——只改顏色，卡帶造型與封面完全不動。

9

zero-specificity 主題層

用 :where([data-theme=…]) 覆寫，不會誤蓋 .dockBtn 等高權重元件；Classic 為預設 :root，可無痕切回。

10

卡帶神聖不可侵

擬物卡帶（形狀、3D 厚度、角色封面、廠牌、接觸點）在所有主題完全一致；主題只動 chrome。
